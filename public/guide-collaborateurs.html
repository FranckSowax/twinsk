产品资料管理指南

如何使用 /request（采购请求） 和 /offer（B2C 优惠） 后台界面：修正价格、联系卖家获取尺寸和重量、维护并更新产品资料。

💡 第一步：把界面切换成中文登录后台后，在左侧菜单底部有一个语言开关，点击 中文 即可把整个后台切换成中文。本指南中的按钮名称与切换后看到的一致。

1登录与两个界面的区别

  1. 打开管理员后台 /admin，输入管理密码登录。
  2. 采购（/admin/requests）：客户提交的采购请求。我们在这里为客户寻找产品、报价。
  3. B2C 优惠（/admin/offer）：面向大众的公开商品目录，发布后生成可分享的链接。

两个界面的产品表格完全相同，操作方法一致。本指南对两者都适用。

2看懂产品表格

每个产品是表格中的一行。主要列：

列含义
来源淘宝 / 1688 / 手动 / 工厂
产品图片 + 标题
价格 (人民币)采购价（人民币）。这是要重点核对的字段。
起订量 / 重量 / 体积 / 尺寸物流信息（用于运费计算）
可靠度卖家回头率、销量、评分
数量 / 利润% / 最终价格报价用

3修正一个价格

⚠️ 重要原则1688 上的产品一定有价格。如果某个产品没有价格，说明是采集不完整，必须去核对并补上真实价格，不能留空或填 0。
  1. 在产品行右侧点击 ✎ 编辑（铅笔图标）。
  2. 在弹窗中找到 价格 (人民币) 字段。
  3. 填入正确的人民币采购价（例如 42.5）。
  4. 点击 保存。

💬 如需要，可先点击该产品行打开详情，再点击 访问网站 打开卖家页面核实当前价格。

4联系卖家获取重量和尺寸

运费按重量和体积计算，所以每个产品都需要准确的 重量 和 尺寸。若资料缺失：

  1. 点击产品行打开详情，再点击 访问网站（卖家的 1688 / 淘宝页面）。
  2. 通过旺旺 / 阿里聊天联系卖家，索取：单件净重（公斤） 和 包装尺寸（长×宽×高，厘米）。是否带电池也要确认。
  3. 拿到数据后，回到产品行点击 ✎ 编辑。
  4. 填写 重量 (公斤) 和 尺寸（例如 70×40×8 cm）。
  5. 点击 保存。
✅ 询问卖家的标准话术「您好，请问这款产品单件净重多少公斤？包装箱尺寸（长×宽×高）是多少厘米？是否含锂电池？谢谢！」

5管理规格（颜色 / 型号）

一个产品可以有多个规格（颜色、尺码、型号）。在 ✎ 编辑 弹窗底部的规格区域：

  1. 为每个规格填写名称（必填）。
  2. 如价格不同，填写该规格的价格；相同则留空。
  3. 尽量为每个规格上传对应图片——这样客户在 /offer 页面点击规格时能看到对应照片。

6手动添加一个产品

  1. 在某个分类卡片右上角点击 ＋ 手动添加。
  2. 填写：产品标题（必填）、价格 (人民币)、图片、卖家、起订量、重量 (公斤)、尺寸、规格。
  3. 点击 保存。

7完成前的检查清单

检查项要求
价格 (人民币)已填写，> 0，与卖家页面一致
重量 + 尺寸已从卖家处确认并填写
规格名称完整，尽量配图
电池如含锂电池需标注（运输限制）
图片清晰、与产品相符

全部核对无误后，产品资料即可用于报价（/request）或发布（/offer）。

Guide de gestion des fiches produits

Comment utiliser les interfaces /request (demandes de sourcing) et /offer (offres B2C) : corriger les prix, contacter les vendeurs pour obtenir dimensions et poids, gérer et mettre à jour les fiches produits.

💡 Étape préalable : passer l'interface en chinoisAprès connexion, un sélecteur de langue se trouve en bas du menu latéral. Cliquez sur 中文 pour basculer tout l'admin en chinois. Les noms de boutons de ce guide correspondent à ce que vous verrez.

1Connexion et différence entre les deux interfaces

  1. Ouvrez l'admin /admin et connectez-vous avec le mot de passe.
  2. Sourcing (/admin/requests) : les demandes envoyées par un client. On y cherche les produits et on chiffre.
  3. Offres B2C (/admin/offer) : un catalogue public ; une fois publié, il génère un lien partageable.

Le tableau produits est identique dans les deux. Ce guide s'applique aux deux.

2Comprendre le tableau produits

Chaque produit est une ligne. Colonnes principales :

ColonneSignification
Sourcetaobao / 1688 / manuel / usine
Produitimage + titre
Prix CNYprix d'achat (yuan). Le champ à vérifier en priorité.
MOQ / Poids / Vol / Dimensionslogistique (calcul du fret)
Fiabilitéréachat, ventes, note du vendeur
Qté / Marge% / Prix finalpour le chiffrage

3Corriger un prix

⚠️ Règle importanteSur 1688, un produit a toujours un prix. S'il n'en a pas, c'est une collecte incomplète : il faut aller vérifier et renseigner le vrai prix, jamais laisser vide ou 0.
  1. À droite de la ligne produit, cliquez sur ✎ Modifier (icône crayon).
  2. Dans la fenêtre, repérez le champ Prix (CNY).
  3. Saisissez le bon prix d'achat en yuan (ex. 42.5).
  4. Cliquez sur Enregistrer.

💬 Au besoin, ouvrez la fiche (clic sur la ligne) puis Visiter le site web pour vérifier le prix chez le vendeur.

4Contacter le vendeur pour le poids et les dimensions

Le fret se calcule au poids et au volume : chaque produit a besoin d'un poids et de dimensions exacts. Si l'info manque :

  1. Cliquez sur la ligne pour ouvrir la fiche, puis Visiter le site web (page 1688 / Taobao du vendeur).
  2. Contactez le vendeur via Wangwang / chat Alibaba et demandez : poids net unitaire (kg) et dimensions du colis (L×l×h, cm). Vérifiez aussi la présence de batterie.
  3. Une fois les données obtenues, revenez sur la ligne et cliquez ✎ Modifier.
  4. Renseignez Poids (kg) et Dimensions (ex. 70×40×8 cm).
  5. Cliquez sur Enregistrer.
✅ Message type au vendeur (à copier)「您好，请问这款产品单件净重多少公斤？包装箱尺寸（长×宽×高）是多少厘米？是否含锂电池？谢谢！」
(Bonjour, quel est le poids net unitaire en kg ? Les dimensions du carton L×l×h en cm ? Contient-il une batterie au lithium ? Merci !)

5Gérer les variantes (couleur / modèle)

Un produit peut avoir plusieurs variantes (couleurs, tailles, modèles). Dans la fenêtre ✎ Modifier, section variantes :

  1. Donnez un nom à chaque variante (obligatoire).
  2. Renseignez un prix par variante s'il diffère ; laissez vide sinon.
  3. Ajoutez si possible une photo par variante — ainsi le client voit la bonne image en cliquant la variante sur /offer.

6Ajouter un produit manuellement

  1. En haut à droite d'une catégorie, cliquez ＋ Produit manuel.
  2. Remplissez : Titre du produit (obligatoire), Prix (CNY), image, vendeur, MOQ, Poids (kg), Dimensions, variantes.
  3. Cliquez sur Enregistrer.

7Check-list avant de terminer

VérificationExigence
Prix (CNY)renseigné, > 0, cohérent avec le site vendeur
Poids + Dimensionsconfirmés auprès du vendeur et saisis
Variantesnoms complets, photos si possible
Batteriesignalée si lithium (restriction transport)
Imagesnettes et conformes au produit

Une fois tout vérifié, la fiche est prête pour le chiffrage (/request) ou la publication (/offer).
